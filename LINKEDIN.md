I built Visual Guard, a visual regression testing project with Playwright and TypeScript.

A checkout flow can still work while its layout quietly breaks. Functional assertions check behavior; screenshot comparisons add a check on appearance.

The project includes:
- 14 passing test cases and 22 screenshot baselines across two viewport sizes.
- Login, products, cart, and checkout coverage.
- A controlled styling regression that the framework detects.
- Expected/actual images, pixel diffs, and traces for investigation.
- A GitHub Actions workflow and an interactive walkthrough.

The demo starts with a clear before-and-after comparison, so you can understand the result without reading a test report.
