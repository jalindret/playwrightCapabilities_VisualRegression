02 / THE ENGINEERING

A small workflow. A useful safety net.

Open the repo, run the suite,
review the evidence.

01

Approve the reference

Capture stable pages with predictable data, fixed viewport sizes, and animation disabled. Review the images before committing.

npm run test:update
02

Compare each run

Playwright compares the current UI with the stored baseline. Functional assertions check that each page reached the intended state.

npm test
03

Inspect the change

Use the HTML report and browser trace to investigate. Approve intentional changes through Git review; fix unintended ones.

npm run report
